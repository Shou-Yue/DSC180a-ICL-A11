# In-Context Learning for Regression via Linear Self-Attention

## **Introduction**

In-context learning (ICL) describes the ability of transformer models to adapt their
predictions based on examples provided in the input sequence, without updating
model parameters. Recent work has shown that, in certain settings, transformers
can implicitly implement learning algorithms such as **gradient descent** entirely
through their forward pass.

This repository contains code for the **regression branch** of a DSC 180A capstone
project that studies how a **one-layer linear self-attention (LSA)** model can
approximate the behavior of **one step of gradient descent** on simple linear
regression tasks.

All experiments are performed using **synthetic regression data**, enabling a
controlled and interpretable analysis of when and how attention-based models
exhibit gradient-descent-like behavior in-context.

## Experiments

### One-Layer LSA vs One-Step Gradient Descent

The main experiment compares predictions produced by a one-layer linear
self-attention model to those produced by an explicit **single gradient descent
step** on the same regression task. The model processes a sequence of context
examples and a query point, and outputs a prediction for the query target entirely
through attention.

### Scaling Experiments

We study how the LSA–gradient-descent correspondence changes as key quantities
are scaled, such as input dimension, number of context points, and batch size.

### Noise Experiments

We evaluate the robustness of the observed behavior by introducing noise into
the regression tasks and measuring how closely LSA predictions continue to match
one-step gradient descent.

---

## Data Generation

All experiments use **synthetic linear regression tasks** generated on the fly
within the notebooks. Each task consists of a randomly sampled ground-truth
weight vector, a small set of context input–output pairs, and a query input
used for evaluation.

No external datasets are required. Details of the data-generation procedure
are documented in `data/README.md`.
